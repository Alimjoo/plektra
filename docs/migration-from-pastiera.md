# Migration from Pastiera

Plektra has a separate package name and does not automatically read another application's private data.

A dedicated migration feature is planned before the first Plektra stable release. It will use a versioned export from Pastiera, show the data included before import, define conflict and repeat-import behaviour, translate legacy preference names, and be tested with Pastiera 0.85 and 0.86 data on the Titan 2 and Titan 2 Elite.

Until that feature is available, do not remove a working Pastiera installation solely to install a Plektra Nightly.
