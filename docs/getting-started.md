# Getting started

Plektra requires Android 10 or newer.

1. Install the APK from the intended release channel.
2. Open Plektra and follow the setup tutorial.
3. Enable Plektra under Android's keyboard management screen.
4. Select Plektra as the current input method.
5. Choose the matching hardware profile and keyboard layout in Settings.

Stable and Nightly use separate app IDs and can be installed together. Google Play variants also use separate identities and do not replace the canonical builds.
