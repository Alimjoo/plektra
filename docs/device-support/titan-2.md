# Unihertz Titan 2

**Support:** Official

The Titan 2 is a primary Plektra test device. Release checks cover physical key input, Shift/Ctrl/Alt/SYM state, status and variation rows, software keyboard visibility, layout switching, and update installation.

The display has conventional lower corners for the current Plektra surfaces. Device-specific key mappings are kept in the bundled hardware profile and can be overridden in Settings.
